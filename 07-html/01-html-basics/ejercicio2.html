Python

Python es un lenguaje de programación de alto nivel, fácil de aprender y
muy versátil. Se utiliza para desarrollo web, automatización, análisis de
datos, inteligencia artificial y creación de aplicaciones. Su sintaxis
clara permite escribir código de forma sencilla y legible.
